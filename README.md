## About the Project

Retail Sales Data Analyzer is a menu-driven Python application built for a practical examination. It reads a CSV dataset, validates and cleans records, calculates sales metrics, supports filtering, exports a report, and creates charts from the dataset.

## Features

- Load and validate `data/retail_sales.csv`.
- Check for missing values and invalid records.
- Calculate total, average, minimum, and maximum sales.
- Analyze revenue by product and category.
- Filter sales records and view top orders.
- Export processed records to `sales_report.csv`.
- Generate bar, pie, line, and correlation heatmap charts.
- Demonstrate abstraction, inheritance, encapsulation, and polymorphism.

## Object-Oriented Programming

| Concept | Implementation |
|---|---|
| **Abstraction** | `Person` is an abstract base class with `display_summary()`. |
| **Inheritance** | `Sales` inherits from `Person`. |
| **Encapsulation** | `Sales.__price` is a private attribute accessed through getter/setter methods. |
| **Polymorphism** | `Sales` implements its own `display_summary()` method. |

The `SalesAnalysis` class manages data loading, cleaning, calculations, filtering, reports, and visualizations.

## Dataset

The input file is `data/retail_sales.csv`.

| Column | Description |
|---|---|
| `Date` | Transaction date |
| `Product` | Product name |
| `Category` | Product category |
| `Price` | Unit price |
| `Quantity_Sold` | Number of units sold |
| `Total_Sales` | Total value of the transaction |

Keep the existing CSV file and its column names unchanged. The program expects these columns as written above.

## Installation and Usage

### 1. Clone the repository

```bash
git clone https://github.com/PalAnghan/Retail_Sales_Data_Analyzer.git
cd Retail_Sales_Data_Analyzer/Practical Exam
```

### 2. Install dependencies

```bash
pip install numpy pandas matplotlib seaborn
```

### 3. Run the program

```bash
python "retail_analyzer.py"
```

Ensure that `data/retail_sales.csv` is present before running the program.
