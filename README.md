## Overview

Retail Sales Data Analyzer reads sales records from a CSV file, validates and cleans the dataset, calculates revenue statistics, filters transactions, exports a report, and generates visualizations. It was created to demonstrate Python programming, Object-Oriented Programming (OOP), data manipulation, and visualization skills.

## Features

- **CSV loading and validation** — checks whether required columns are available.
- **Data cleaning** — removes duplicates and records with missing or invalid values.
- **Sales statistics** — calculates total, average, maximum, and minimum revenue using NumPy.
- **Product and category analysis** — groups and summarizes sales with Pandas.
- **Filtering** — searches by product or category and displays the top 10 orders.
- **Report export** — saves the processed data as `sales_report.csv`.
- **Four visualizations** — bar chart, pie chart, monthly line chart, and correlation heatmap.
- **Chart export** — saves plots in the `charts/` folder.
- **OOP principles** — demonstrates abstraction, inheritance, encapsulation, and polymorphism.
- **Menu-driven CLI** — offers numbered options for using the application.

## Object-Oriented Programming

| Concept | Implementation in this project |
|---|---|
| **Abstraction** | `Person` is an abstract base class with `display_summary()`. |
| **Inheritance** | `Sales` inherits from `Person`. |
| **Encapsulation** | `Sales.__price` is private and accessed through getter/setter methods. |
| **Polymorphism** | `Sales` implements its own `display_summary()` method. |

`SalesAnalysis` manages the CSV loading, cleaning, calculations, filtering, reporting, and visualization features.

## Dataset

Input file: `data/retail_sales.csv`

| Column | Description |
|---|---|
| `Date` | Date of the transaction |
| `Product` | Product name |
| `Category` | Product category |
| `Price` | Price per unit |
| `Quantity_Sold` | Number of units sold |
| `Total_Sales` | Total transaction value |

**Important:** The column names in the CSV must match the names above exactly because the Python code uses `Quantity_Sold` and `Total_Sales`. `Total_Sales` is used as the revenue measure.

## Installation and Usage

### 1. Clone the repository

```bash
git clone https://github.com/PalAnghan/Retail_Sales_Data_Analyzer.git
cd Retail_Sales_Data_Analyzer
```

### 2. Install dependencies

```bash
pip install numpy pandas matplotlib seaborn
```

### 3. Run the program

```bash
python retail_analyzer.py
```

Make sure `data/retail_sales.csv` exists before running the program.
